# Project11 HIS — Hospital Information System

## Project Overview
Project ini berisi prototipe antarmuka pengguna (UI) untuk tiga modul Sistem Informasi Manajemen Rumah Sakit (SIMRS).

## Modules

### 1. Nursing / Keperawatan
Prototipe antarmuka untuk mendukung aktivitas dan dokumentasi keperawatan.

Folder: `perawatan/`

### 2. IGD / Instalasi Gawat Darurat
Prototipe antarmuka untuk modul pelayanan gawat darurat.

Folder: `igd/`

### 3. Inventory / Inventaris dan Gudang
Prototipe antarmuka untuk pengelolaan inventaris dan persediaan.

Folder: `inventaris/`

## Implementation Status
File HTML untuk ketiga modul telah diunggah ke repository. Pengujian fungsi, integrasi backend dan database, serta validasi hak akses perlu dilakukan sesuai kebutuhan proyek.

## Technology
- HTML
- CSS dan JavaScript jika disertakan dalam file prototipe

## Notes
Repository ini merupakan bagian dari proyek pembelajaran. Prototipe tidak boleh dianggap sebagai sistem rumah sakit siap produksi sebelum keamanan, autentikasi, hak akses, dan integrasi data diuji.

Gunakan data dummy untuk demonstrasi. Jangan mengunggah informasi pasien atau data rumah sakit yang bersifat rahasia.
